## 🚀 Hướng Dẫn Sử Dụng (Getting Started)

### Clone repository về máy:

```bash
git clone https://github.com/BinCry/BTVN.git
cd BTVN
```

### Mở bài thực hành web

Các bài dùng HTML, CSS và JavaScript thuần, không cần cài thư viện hay chạy lệnh build.

1. Mở thư mục repository bằng VS Code.
2. Mở file HTML của bài cần xem; khuyến nghị chọn **Open with Live Server** nếu đã cài tiện ích Live Server.
3. Có thể mở trực tiếp file HTML bằng trình duyệt. Các liên kết trong README dẫn đến mã nguồn trên GitHub, không phải trang web đã triển khai.

### Bài 15 — đổi ba kiểu mục lục

Mở `BaiLam_BT3_2/15-Frames/index.html` để xem đầy đủ ba khung: tiêu đề phía trên, mục lục bên trái và nội dung bên phải. Chọn kiểu trong ô **Mục lục** ở phần tiêu đề:

| Kiểu mục lục | Đuôi địa chỉ khi mở bài 15 |
| :--- | :--- |
| 1. Tờ giấy | `index.html?menu=paper` |
| 2. Khung lá | `index.html?menu=leaves` |
| 3. Nút xanh (mặc định) | `index.html?menu=buttons` |

- Cả ba kiểu dùng chung 13 bài: Mẹ, Phú Quốc, Định dạng văn bản, Truyện ngụ ngôn, Shop hoa tươi, Excite@Home, Chương trình học, Double Rich, Free.com, Việt Nam, Form đăng nhập, Phiếu đăng ký và Đặt tour.
- Bấm một mục để đổi nội dung ở khung bên phải. Đổi kiểu mục lục không làm mất bài đang mở.
- Mẫu tờ giấy có khung nét đứt nghiêng theo dòng đang chọn; khung cập nhật khi chuyển bài hoặc bấm Back/Forward.
- Bấm **Bật nhạc** hoặc **Tắt nhạc** trên tiêu đề để điều khiển nhạc nền; nhạc không tự phát.
- `header.html`, `menu.html`, `menu-paper.html` và `menu-leaves.html` chỉ là từng khung riêng, không phải trang bắt đầu đầy đủ.
- Thư mục `15-Frames/pages/` chứa bản sao các bài và tài nguyên cần thiết. Bài 15 chạy độc lập, không cần liên kết sang thư mục Web1 hoặc Web2; bản bài làm tuần trước được giữ nguyên.

Bài 15 giữ `frame`/`frameset` theo chủ đề thực hành HTML cũ. Các bài khác dùng trang HTML riêng; không cần mở thông qua bài 15.
