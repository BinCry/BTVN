## 🚀 Hướng Dẫn Sử Dụng (Getting Started)

### Clone repository về máy:
```bash
git clone https://github.com/BinCry/BTVN.git
cd BTVN
```

### Quy ước đặt tên bài nộp (Khuyến nghị):
- **Tên folder môn:** `Tên môn học tiếng Việt có dấu hoặc không dấu` (ví dụ: `Công nghệ web và ứng dụng`)
- **Tên folder bài làm:** `[MSSV]-[Họ và Tên]-[Tên Lab/Bài Tập]` (ví dụ: `24521449-PhamMinhQuan-Web1`)
